### 概要

这次同步把上游从 0.2.2-rc.5 的发布点推进到 0.2.3-alpha.2。主线上新落地的能力集中在连接器、Computer Use、会话与 Web 交互，同时收紧了 Node.js 运行时下限。

飞书、企业微信、钉钉、腾讯会议和腾讯文档作为可选插件进入 `packages/connector/`，分别走官方 CLI 或托管 MCP。远程浏览器配对从实验路径收进 `packages/client/remote-connection`，设置页可以发一次性二维码或带 token 的登录链接。

Web 侧把个性化推荐做成默认挂载，并取消了原来的可选 bundle。Office 技能收成单一 `office` 入口。Node PTC 默认改为进程内持久的 scoped REPL。CUA 在 macOS/Windows 上补了系统输入、跨回合保持的按键/鼠标，以及 macOS 近期窗口活动提醒。

同一批提交还带来一批会破坏现有配置或调用的重命名与删除，升级说明集中在 `docs/upgrade-guide/v0.2.2-rc.5/` 和 `docs/upgrade-guide/v0.2.3-alpha.1/`。

### 新功能 / 行为变化

- 连接器：`packages/connector/feishu`（官方 `lark-cli` 与插件页登录）、`wecom`（`wecom-cli`）、`dingtalk`（`dws`）、`tencent-meeting`（`tmeet`）只支持 macOS 与 Windows x64；`tencent-docs` 经共用 MCP 管理器做 OAuth。`cli-account` 与 `upstream-skills` 为这类 CLI 插件提供账号注册和上游技能缓存（#8727）。
- 远程连接：新包 `@deepseek-ai/dsh-client-remote-connection`。owner 在共用登录页通过二维码或凭据链接配对浏览器（#7675）；回环地址的登录 URL 已单独修好（#8920）。
- 会话：`packages/session/tool-session-control` 在 Web profile 提供默认关闭的 `session_send_message`，向另一个普通会话发消息并只等接收回执，不支持 subagent 目标（#8241）。`list_agents` 的结构化结果改为 `{ running, limit, agents }`。SDK 会报告 session agent 被销毁的原因（#8738）。未传时区的 SDK prompt 改为上报进程时区（#8081）。
- 个性化推荐：删除 `@deepseek-ai/dsh-personalized-recommendations`。`@deepseek-ai/dsh-web-app` 默认挂载 action-cards、creation-recommendations、plugin-recommendations 及对应 UI 行；开关在「设置 → 通用设置」（#8647）。操作卡片 UI 从 `packages/experimental/client-ui-action-cards` 移到 `packages/client/ui-action-cards`。后续轮次的新提案不再把尚未开始的旧卡片标成 `replaced`（#8900）。持久化新增 `action-cards/decision` 事件。
- Office：内置技能只保留 `office`，Word / PowerPoint / Excel 指导内联在 `office/SKILL.md`；`tool-office` 的默认 `activationSkills` 改为 `[office]`（#8061）。同批还合入 Office PDF 技能（#7850）。
- PTC：`@deepseek-ai/dsh-ptc-runtime-node` 在未配置 `executionMode` 时默认 `persistent-in-memory` + scoped REPL，程序格式记为 `scoped-repl`。顶层 `return` 会被拒绝，完成值是最后一条顶层表达式（#8848）。显式 `executionMode` 的配置保持原样。workflow 工具仍留在 PTC executor overlay（`b67be0905d` 的 revert）。
- CUA：`useSystemPointer` / `systemPointer` / `requireSystemPointerApproval` 改为系统输入对应字段，错误码前缀改为 `SYSTEM_INPUT_*`（#8714）。macOS 与 Windows 的显式 key/mouse down 会跨程序、跨回合保持，成功结束时用 system reminder 报告仍按住的输入（#8713）。macOS helper 握手增加 `recentActivityWindowMs`，下一步之前可以报告近期窗口活动，也可用 `"off"` 关掉（#6423）。另有 action schema discovery（#8710）。持久化新增 cua 活动上下文和 held-input / inputs-released 通知来源。
- Web / 桌面：时间线增加「跟随聊天语言」、可点击进度条和带标签的会话讨论历史（#8630）。工作区选择器可搜索（#8394）。输入框可用 ArrowUp / ArrowDown 召回已加载的 prompt（#8359），并增加行内 placeholder 插槽（#8904）。模型目录里的提供方模型可以编辑 reasoning levels（#8827）。API key 的 DeepSeek 提供方显示名改为 DeepSeek API（#8490）。桌面应用菜单增加 Settings（#8663）。系统消息改为按章节增量下发，消费方必须累计仍存活的章节（#6941）。压缩标记去掉视图里的 Markdown `summary`，改为用 `summaryEventSeq` 去读 `compaction/summary` 事件。归档清理不再受创建者沙箱策略约束，干净 worktree 在归档时会删掉，除非 `retainOnArchive: true`。
- 图片请求：硬上限 `maxImageBytes` 与软目标 `imageTargetBytes` 分开。pi 的 `requestImageMaxBytes` 现在限制编码后单图字节，`requestImageBudgetCount` 默认 20。DeepSeek 的 `imageMaxBytes` 更名为 `imageTargetBytes`（默认仍 2 MiB，硬上限 32 MiB）（#8716）。

### 破坏性变更或升级注意点

升级说明以新增的中文 guide 为准，下面是会改变安装、配置或调用的部分。

- Node.js：`engines.node` 从 `>=24.9.0` 改为 `^24.22.3 || >=26.13.1`。更早的 24.x 和 26.13.1 之前的 26 不再支持。源码、npm 安装、CI，以及 Python SDK 显式 `DSH_RUNTIME_MODE=node` 都受影响。打包的桌面端和 Python SDK 自带的 Node 已是 24.22.3。见 `docs/upgrade-guide/v0.2.3-alpha.1/node-24-22-3/`。
- 个性化推荐 bundle 会在加载 profile 时从 `dsh.profile.bundles` 删除。`cordis.patch.yml` 里对那六行的 `disabled: true` 仍会压过总开关。
- `/office-docx`、`/office-pptx`、`/office-xlsx` 已不存在。同名的用户技能不再覆盖内置指导，只作为独立技能。自定义 `assetRoot` 只需 `office/SKILL.md`。
- 省略 `executionMode` 的 PTC 调用不能再写顶层 `return`，调用之间会保留绑定。要维持旧行为，在 profile patch 里写 `executionMode: per-call`（patch 会替换整个 `config`）。
- `ctx.sessionQuery.inspectSession` 已删除。冷会话改为 `observeSession` 后读 `observation.projections?.values[key]`。第三方插件里的旧调用无法通过类型检查。
- `list_agents` 不再直接返回数组，调用方要遍历 `result.agents`，容量看 `running` / `limit`。
- CUA 字段、配置项和 `MOUSE_*` 错误码已换名。自定义 `helperPath` 必须接受 `getHeldInputs` / `releaseHeldInputs`，macOS 握手还要带 `recentActivityWindowMs`，旧 helper 会拒绝。Windows 暂不开放系统输入能力。
- DeepSeek 模型配置里的 `imageMaxBytes` 会被拒绝，需改为 `imageTargetBytes`，且不得超过 32 MiB。`ImageRequestTarget.maxBytes` 改为 `maxImageBytes`。
- SDK / JSON-RPC 不传时区时，模型看到的是进程时区（容器里经常是 UTC），不再是 `unavailable`。非法显式时区（例如 `CST`）会使请求失败。持久化在不带 `rpcId` 的 user 来源上记录可选的 `clientTimeZone`。
- 系统章节：后续 `system/message` 是增量而不是整段提示词。自定义循环要在每次模型尝试前调用 `PromptAssembly.systemUpdates(retry)`。自定义组合必须先加载 `session-projection` 再使用 `system-prompt`。
- 归档：只读沙箱的创建者不再保留检出目录。需要保留时设置 worktree 的 `retainOnArchive: true`。
